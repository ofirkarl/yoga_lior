# יוגה עם ליאור

אפליקציית ווב לסטודיו "יוגה עם ליאור": הרשמה לשיעורים, ניהול כרטיסיות, ובהמשך תשלום דרך Grow.

## מטרות

1. **נגישות:** ממשק פשוט וברור בעברית, מימין לשמאל, לפי WCAG 2.1 AA.
2. **אבטחת מידע:** כל מתאמנת רואה רק את הנתונים שלה. פרטי אשראי לא נשמרים כאן. הצהרות בריאות פתוחות למנהלת בלבד.
3. **ווב קודם:** אפליקציית ווב שאפשר להתקין למסך הבית, ובהמשך לעטוף לחנויות.
4. **כניסה:** חשבון גוגל, או שם משתמש וסיסמה שליאור יוצרת ומאפסת.

## מבנה

| תיקייה | תוכן |
| --- | --- |
| `supabase/migrations` | סכמת בסיס הנתונים, כללי Row Level Security והפונקציות |
| `supabase/seed.sql` | המחירון והמערכת השבועית מהשאלון |
| `supabase/tests` | בדיקות אבטחה וחוקי הרשמה על Postgres מקומי |

## הרצת הבדיקות

דורש Postgres 16 מקומי:

```bash
supabase/tests/run.sh
```

הבדיקות מריצות את הסכמה על סביבה שמדמה את Supabase ובודקות, בין השאר, שמתאמנת לא רואה נתונים של אחרות, לא יכולה לשדרג את עצמה, לא יכולה ליצור לעצמה כרטיסייה, ושמועדי הביטול וההחזרים מחושבים נכון.

## חוקים עסקיים (ברירות מחדל, ניתנות לשינוי בטבלת `settings`)

| כלל | ערך |
| --- | --- |
| שיעור בוקר | מתחיל לפני 12:00 |
| ביטול חינם, שיעור בוקר | עד 20:00 בערב שלפני |
| ביטול חינם, שיעור ערב | עד 3 שעות לפני |
| הרשמה מראש | עד 30 יום |
| גודל קבוצה | 3 עד 8 |
| ביטול מאוחר או אי-הגעה | יורד ניקוב |
| שיעור מלא | רשימת המתנה, עלייה אוטומטית כשמתפנה מקום |
| מתאמנת חדשה | נכנסת אחרי אישור של ליאור ומילוי הצהרת בריאות |

## כללי אבטחה למפתחים

- אין כתיבה ישירה מהלקוח לטבלאות `bookings`, `entitlements` ו-`payments`. כל שינוי עובר דרך פונקציה.
- פונקציה חדשה סגורה כברירת מחדל. צריך לפתוח אותה במפורש עם `grant execute ... to authenticated`, ורק אם היא בודקת הרשאות בעצמה.
- מפתח `service_role` של Supabase נשמר רק בצד השרת (Edge Functions), אף פעם לא בקוד האפליקציה.
